# ПРУФ · статус проекта (0.9.4)

Этот файл — единая точка входа для продолжения работы. Если сессия или песочница упала —
читать сначала его, затем `CONTEXT.md` и `docs/anti-relay.md`.

## 0. Главное в одном абзаце

ПРУФ — платформа верификации понимания кода для найма. Ядро детерминированное, без LLM,
работает офлайн. Версия 1 («защита мутациями», порт 8777) уязвима к фото-атаке: дифф,
вопрос и варианты ответа живут в одном кадре, значит скриншот решается внешней моделью.
Версия 2 (АРП-2 «Оракул») закрывает это архитектурно: ответа нет на экране вообще.

Правило проекта: **любая проверка, ответ на которую выводится из содержимого экрана, мертва.**

## 2. Что проверено прогоном ядра АРП-2

`python3 tools/smoke_arp.py` на демо-задаче «Разбор заказов» (полный сеанс — около 1 секунды,
без сети). Подтверждено фактическим запуском:

1. **Сборка сессии** — 8 гипотез из мутаций самого решения, все попарно различимы по пулу
   зондов, порог улик равен log2(k) = 3.
2. **Аксиома A1 (в кадре нет ответа)** — 10 сессий с разными скрытыми правками дают
   **один и тот же `screen_digest`**. Скриншот не содержит ни одного бита об ответе.
3. **Аудит утечек** — `audit_public()` пуст, в публичном виде нет ключей из `FORBIDDEN_KEYS`,
   фаза A вообще не отдаёт список гипотез.
4. **Аксиома A2 (ответ добывается взаимодействием)** — зонд отдаёт ровно один бит;
   отклоняются импорты, атрибуты, сторонние имена и выражения без вызова; отклонённый
   зонд не тратит бюджет (7).
5. **Аксиома A3 (ответ без доказательства не считается)** — попытка назвать гипотезу
   до порога даёт `not_enough_evidence` (409) и не тратит попытку.
6. **Честный путь** — зонды сужают множество до одной гипотезы, ловушка ловит скрытую
   правку, вердикт `control`, аудит экрана чистый, протокол содержит обе границы.
7. **ОБЭ (ответ без эвиденса)** — верная метка при более чем одной совместимой гипотезе
   даёт 0.0 и флаг ОБЭ, индекс делегирования ≥ 30.
8. **Воспроизводимость** — один сид даёт ту же скрытую правку и тот же пул зондов;
   ловушка, падающая на оригинале, отклоняется; сессия не переоткрывается.

### Найдено прогоном: точная граница инстанса бывает меньше log2(k)

Зонд даёт один бит, но раскладывает множество неравномерно: на удачном входе два зонда
уже оставляют одну гипотезу из восьми. Значит, жёсткий порог log2(k) иногда
отклоняет уже **доказанный** ответ и заставляет сжечь лишний зонд.

Решение (плановая правка `submit_identify`): гейт ставится не на счётчик, а на доказательство:

```python
alive = consistent_set(session)
proved = len(alive) == 1 and alive[0] == secret["active"]
if not proved and len(session["probes"]) < session["min_probes"]:
    raise ArpError("not_enough_evidence", ..., 409)   # попытка не тратится
```

Важное ограничение: **показывать на экране можно только порог log2(k)**. Точная граница
инстанса зависит от скрытой правки, и если вывести её в интерфейс, она сама станет
битом информации и сломает A1. Обе границы попадают только в итоговый протокол,
после завершения сессии.

`tools/smoke_arp.py` специально написан так, чтобы быть зелёным и до, и после этой правки
(функция `identify_active` добирает зонды при `not_enough_evidence`).

## 3. Ограничения среды, из-за которых теряется работа

- Песочница агента обнуляет `/data/pruf` между шагами (за две сессии — шесть раз).
  Поэтому единственное хранилище — репозиторий. Правило: сначала push, потом запуск.
- **В песочнице отключена сеть** (DNS не резолвится): `git clone`, `curl`, `pip install` не
  работают, `tools/restore.sh` в такой сессии бесполезен. Восстановление возможно только
  файл за файлом через интеграцию GitHub (чтение содержимого + запись в песочницу).
- Архив `Stapel_Project_Package+pruf-platform_concepts4.zip` (10 МБ) из песочницы недоступен по
  той же причине. Дизайн-система берётся из уже собранных `web/css/app.css` и `web/index.html`.
- В аргументах инструментов использовать только живую кириллицу, не escape-последовательности:
  вылет прошлой сессии был именно на разборе экранированной кириллицы.

## 6. Известные не-баги (не тратить на них время)

- `web/session.html` без параметра `?demo=1` или `?id=s-...` пуст по замыслу.
- Табы «репозиторий / файл» живут внутри модалки «Новая проверка» в кабинете работодателя.
- Горизонтальный скролл внутри `.code-body` — так задумано.
- `/api/session/start` возвращает 422, если базовое решение не проходит свои же тесты.
- В браузерном QA два skip — клики перекрыты модалкой «Проверка готова».
