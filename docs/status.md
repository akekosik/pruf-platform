# ПРУФ · состояние проекта (версия 0.9.3, 15.09.2026)

Этот файл — точка входа после любого сбоя среды. Сначала прочитать его, затем `CONTEXT.md` и `PLAN.md`.

## 1. Восстановление одной командой

```bash
git clone --depth 1 https://github.com/akekosik/pruf-platform.git /data/repo \
  && bash /data/repo/tools/restore.sh
```

`restore.sh` делает всё: клон → `tools/apply_fixes.py` → `tools/apply_fixes_2.py` → 65 автотестов → сервер на порту 8777 → проверка `/api/health`.

## 2. Что проверено и зелёное

| Проверка | Команда | Результат |
| --- | --- | --- |
| Юнит-тесты ядра | `python3 -m unittest discover -s tests` | 65 тестов, OK |
| HTTP API end-to-end | `python3 tools/qa_api.py --base http://127.0.0.1:8777` | 71 проверка, 0 падений |
| Браузер: все кнопки | `node tools/qa_browser.js --base http://127.0.0.1:8777 --out /data/qa` | 123 клика, 0 падений, 2 пропуска |
| Вёрстка 390/1440 px | `node tools/qa_layout.js` | без боковой прокрутки, ничего не обрезано |

Два пропуска в браузерном QA — ожидаемое поведение: клик по ссылке «Моё решение» и по бургеру на `session.html` перекрыт модальным окном «Проверка готова», пока защита не начата.

## 3. Что починено в 0.9.2–0.9.3

1. Строки кода прокручиваются внутри своей карточки, а не тянут страницу.
2. Варианты ответа в блоке «Попробуйте на примере»: колонка грида была 654 px при экране 390 px (`1fr` берёт минимум по min-content) — текст вариантов обрезался. Исправлено `minmax(0, 1fr)` + переносы.
3. Секции с reveal-анимацией видны, даже если JS не загрузился (класс `has-js`).
4. Драйвер QA: сначала десктоп, пролистывание до скриншота, мобильные кнопки жмутся в мобильном контексте, клик под модалкой — пропуск, а не падение.
5. Метрика «горизонтальная прокрутка» переделана: `scrollWidth` давал ложные срабатывания, теперь проверяется реальный `window.scrollX` плюс отдельно — обрезанный контент без скроллируемого предка.

## 5. Особенности, которые легко принять за баг

- `session.html` без параметров ждёт сессию: нужно `?demo=1` или `?id=s-...`.
- Вкладки «Ссылка на репозиторий / Загрузить файл» живут внутри модального окна «Новая проверка» в кабинете работодателя.
- Горизонтальная прокрутка внутри `.code-body` — норма: длинные строки кода скроллятся в карточке.
- Если базовое решение не проходит свои же тесты, `/api/session/start` отвечает 422 — так задумано.

## 7. Техническое ограничение про приватность репозитория

Видимость уже существующего репозитория из среды агента переключить нельзя. Если сделать репозиторий приватным вручную, чтение и пуш через GitHub-интеграцию продолжат работать, но анонимный `git clone` в песочнице перестанет работать — сценарий восстановления из раздела 1 потребует токена или пофайловой выгрузки через интеграцию.
